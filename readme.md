## Projects

### 🐱🐶 Cats vs Dogs Image Classification Web Application
Located in [`cats_vs_dogs/`](./cats_vs_dogs)

A full-stack, production-quality deep learning application for classifying images as **Cat** or **Dog** using a Keras model.

- **Backend:** FastAPI microservice (`backend/`) running TensorFlow inference on `model.keras`.
- **Frontend:** Streamlit web dashboard (`frontend/`) communicating via HTTP REST APIs.
- **Jupyter Notebook:** Model training and evaluation notebook ([`cats_vs_dogs_identifier.ipynb`](./cats_vs_dogs/cats_vs_dogs_identifier.ipynb)).

For setup, architecture, and API documentation, see the [Cats vs Dogs Documentation](./cats_vs_dogs/README.md).
